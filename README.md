# VELOOP Games

Full-stack rewards gaming platform built with MERN.

## Stack

- React + Vite
- Bootstrap 5
- CSS Modules
- React Router
- Lucide React
- Framer Motion
- Node.js + Express
- MongoDB + Mongoose
- JWT + bcrypt

## Structure

```text
VEloops/
├── client/   # React frontend
└── server/   # Express API
```

This project is being built incrementally from the VELOOP Games assignment requirements.
